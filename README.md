# حصصي

تطبيق ويب (PWA) لحساب مصاريف الحصص، وتسجيل الغياب، ومتابعة التحصيل ومستلزمات مشروع التخرج. بيشتغل على الموبايل من غير نت، وكل البيانات متخزنة على الموبايل نفسه.

## الرفع على GitHub Pages

1. اعمل Repository جديد (مثلاً `hesasy`).
2. ارفع كل الملفات اللي في الفولدر ده زي ما هي.
3. من **Settings ← Pages**: اختار `Deploy from a branch`، والفرع `main`، والفولدر `/ (root)`.
4. بعد دقيقة هيبقى الرابط: `https://USERNAME.github.io/hesasy/`
5. افتح الرابط من Chrome على الموبايل، ومن القائمة اختار **"تثبيت التطبيق" / "إضافة للشاشة الرئيسية"**.

## ملاحظات مهمة

- البيانات بتتحفظ على الموبايل بس. اعمل نسخة احتياطية في فولدر على الموبايل من الإعدادات، وشاركها على Drive من وقت للتاني.
- لو مسحت بيانات Chrome أو غيرت الموبايل، استرجع البيانات من ملف النسخة الاحتياطية.
- لو عدلت أي ملف، غيّر رقم `VERSION` في `sw.js` علشان التحديث يوصل للموبايل.
